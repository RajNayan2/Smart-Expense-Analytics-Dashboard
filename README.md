# Smart Expense Analytics Dashboard

A responsive expense management dashboard designed to help users track daily spending, manage budgets, categorize transactions, and analyze their personal finances.

## Features

- Add and manage income and expense transactions.
- Categorize transactions for better organization.
- Track daily expenses and total spending.
- Analyze spending patterns.
- Manage and monitor budgets.
- Store transaction data using Browser LocalStorage.
- Responsive and user-friendly interface.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage API
